# 송다원 | Java Backend Portfolio

Java 백엔드 개발자로서의 실무 경험과 프로젝트 수행 내용을 정리한 개인 포트폴리오입니다.

Java와 Spring 기반 웹 애플리케이션 개발 경험을 중심으로 담당 업무, 주요 구현 기능, 사용 기술을 소개합니다.

## 주요 내용

- **About** — 개발자 소개 및 경력
- **Skills** — 사용 기술 및 개발 환경
- **Experience** — 실무 경험과 담당 업무
- **Projects** — 주요 프로젝트 및 기능 구현 사례

## Tech Stack

| Category | Technologies |
|---|---|
| Backend | Java, Spring MVC, MyBatis |
| Database | MySQL, Oracle |
| Frontend | JavaScript, jQuery, JSP, JSTL |
| Server | Apache Tomcat |
| Portfolio | HTML5, CSS3, JavaScript |

## 주요 개발 경험

- 심리검사 서비스의 응답 처리 및 결과 데이터 연동
- KG이니시스 결제 API 연동
- 소셜 로그인 기능 구현
- CLIP Report 기반 리포트 연동
- 게시판 및 웹 서비스 기능 개발

각 사례는 실제 담당 업무와 구현 경험을 바탕으로 작성했습니다.

## 실행 방법

별도의 설치나 빌드 과정 없이 `index.html` 파일을 브라우저에서 열면 실행할 수 있습니다.

