# 송다원 Java Backend Portfolio

기존 슬라이드 디자인과 애니메이션을 유지한 Java 백엔드 개발 포트폴리오입니다. `index.html`을 열어 확인할 수 있습니다.

## 내용
- 실무 경험과 교육 기술의 구분
- 심리검사 응답 유지, 검사별 데이터 변환과 외부 API 연동
- KG이니시스 결제, 카카오·네이버 로그인, CLIP report 출력, 게시판
- 완료한 구현과 향후 개선 방향을 구분한 회고

## 조작
- 이전·다음 버튼, 좌우 방향키, 오른쪽 진행 표시로 이동합니다.
- 데스크톱에서는 휠로 슬라이드를 전환합니다.
- 모바일에서는 스크롤로 본문을 읽고 버튼으로 이동합니다.
- 운영체제의 동작 줄이기 설정을 존중합니다.

## 구성
- slides.js: 콘텐츠와 기존 슬라이드 렌더링·전환
- styles.css: 기존 폰트, 색상, 카드 구성과 등장·호버 애니메이션
- fonts/: 기존 Pretendard 폰트

콘텐츠는 확인한 구현과 담당 경험에 근거합니다. 업무 소스와 인증 정보는 포함하지 않으며, 확인되지 않은 성능 수치나 수행하지 않은 개선을 성과로 적지 않습니다.
