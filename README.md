# 송다원 Java Backend Portfolio

Java 백엔드 개발 경험을 소개하는 HTML/CSS/JavaScript 포트폴리오입니다. `index.html`을 열면 동작하며 빌드나 서버가 필요하지 않습니다.

## 디자인

이전 MyPortfolio 버전의 큰 타이포그래피, 비대칭 구성, 연결선과 공간감 있는 전환을 참고했습니다. MyPortfolio 원본은 수정하지 않았습니다.

- 상시 왼쪽 목차를 덜어내고 넓은 화면을 사용합니다. 하단 목차와 이전·다음 버튼으로 이동합니다.
- 소개는 큰 Backend / Developer 타이포그래피와 자동 응답 처리 도식으로 구성합니다.
- 기술은 서버·데이터·화면 기술의 관계가 보이는 타이포그래피로 설명합니다.
- 경력과 작업 방식은 차콜 바탕, 구현 기록은 밝은 종이 바탕으로 구분합니다.
- 버밀리언은 주요 강조, 올리브는 데이터·결과, 샌드는 어두운 화면의 강조에 사용합니다.
- Pretendard를 유지하며 작은 화면에서는 구성을 다시 쌓아 읽습니다.

## 조작과 접근성

- 목차, 이전·다음 버튼, 좌우 방향키와 주소 해시로 사례를 이동합니다.
- 이동 버튼은 화면 하단에 고정됩니다. 본문 안에 별도 스크롤 영역을 두지 않습니다.
- 작은 화면에서는 일반 문서 스크롤을 사용합니다. 데스크톱에서 본문이 모두 들어올 때는 휠로 사례를 이동합니다.
- 소개의 흐름은 자동 반복합니다. 일시정지·재개·단계 선택이 가능하며 관련 링크에 포커스가 들어가면 정지합니다.
- 응답 유지 데모는 선택과 페이지 왕복에 따른 저장·복원 피드백을 보여줍니다.
- 동작 줄이기 설정에서는 자동 시작과 위치 변화 애니메이션을 생략합니다. 키보드 이동도 즉시 전환합니다.

## 콘텐츠

실무와 교육 기술, 완료한 구현과 향후 개선 방향을 구분합니다. 심리검사, 결제, 소셜 로그인, CLIP report와 게시판 사례는 확인한 코드와 담당 경험에 근거합니다. 확인하지 않은 트랜잭션·롤백·성능 개선을 성과로 적지 않았습니다.

응답 유지 데모는 예시 4문항을 메모리에 저장하며 새로고침하면 초기화됩니다. 실제 검사나 채점·응답 전송을 하지 않습니다. 소개와 변환 도식도 원리 설명용이며 실제 API를 호출하지 않습니다. 변환 예시 출력은 실제 formatAnswers 함수와 대조했습니다. 리포트는 실제 출력물 대신 연동 구조를 표현합니다. 업무 소스와 인증 정보는 포함하지 않습니다.

## 파일

- `index.html`: 이름, 본문, 고정 탐색, 진행선
- `slides.js`: 콘텐츠, 사례별 렌더링, 자동 흐름, 응답 유지와 전환
- `styles.css`: 서체와 디자인 체계, 반응형과 상태
- `fonts/`: Pretendard 로컬 폰트
