# 송다원 Java Backend Portfolio

Java 백엔드 개발 경험을 소개하는 HTML/CSS/JavaScript 포트폴리오입니다. `index.html`을 열면 동작하며 빌드나 서버가 필요하지 않습니다.

## 디자인과 정보 구조

- 전체 14개 화면에서 맥락 제목과 핵심 메시지의 크기·굵기·색을 나눴습니다. 보조 제목은 중성색으로 낮추고 버건디는 핵심 동작과 결과에 집중합니다.
- 경력은 담당 업무, 기술은 Java·Spring MVC, 결제는 승인 호출, 데이터는 결과 필드, 회고는 다음 개선을 먼저 읽도록 구성했습니다.
- 데이터 변환은 예시 응답 → formatAnswers → 검사별 전달 형식 도식으로 설명합니다. 예시 출력 세 가지는 실제 구현 함수와 대조했습니다.

- 장식용 챕터 배지, 그라데이션 제목, 슬라이드 카드 프레임을 제거했습니다.
- 이름이 보이는 데스크톱 목차와 모바일 고정 이동 메뉴로 사례를 탐색합니다.
- 경력은 업무 범위, 기술은 사용 맥락, 결제는 처리 순서, 로그인은 회원 분기 구조로 설명합니다.
- Pretendard를 유지하고 첨부 팔레트인 버건디 `#790D16`, 샌드 `#E5D3AF`, 크림 `#F5EFE1`, 블루그레이 `#AEC4D4`로 통일했습니다. 이미지의 샌드 실제 색상과 표기는 `#E5D3AF`입니다.
- 입력 영역과 참고 설명을 구분하고 표·목록·실제 조작이 필요한 영역에만 경계를 사용합니다.

## 조작

- 목차, 이전·다음 버튼, 좌우 방향키로 이동합니다.
- 모든 화면에서 이동 메뉴는 화면 하단의 같은 위치에 고정됩니다. 본문과 목차에 내부 스크롤 영역을 두지 않습니다.
- 소개, 기술과 회고의 중복 설명을 줄여 기본 화면에서 읽을 분량으로 정리했습니다. 작은 화면이나 확대 환경에서 필요한 경우에는 일반 페이지 스크롤을 사용합니다.
- 입력 요소에서 방향키를 사용하면 해당 요소의 기본 동작을 유지합니다.
- 작은 화면에서 내용이 넘치면 일반 페이지를 스크롤합니다. 데스크톱에서 본문이 모두 들어오는 경우에는 휠로 사례를 전환합니다.
- `#skills`, `#payment`, `#psychology` 등 주소 해시로 사례를 바로 열 수 있습니다.
- 사례 전환에는 방향감 있는 움직임, 본문에는 짧은 순차 등장·스크롤 진입 효과를 사용합니다. 키보드 조작과 동작 줄이기 설정에서는 생략합니다.

## 콘텐츠와 데모

첫 화면의 ‘응답이 결과가 되는 과정’은 진입 시 자동으로 시작해 입력·상태 유지·API 전달·결과 조회를 계속 순환합니다. 일시정지와 계속 보기, 단계 직접 선택이 가능합니다. 단계에 따라 핵심 설명과 관련 사례 링크가 바뀝니다. 실무의 처리 흐름을 설명하는 도식으로 실제 API를 호출하지 않습니다. 다른 사례로 이동하거나 탭이 숨겨지면 재생을 정지하고, 숨기기 전 재생 중이었다면 돌아올 때 재개합니다. 동작 줄이기 설정에서는 자동으로 시작하지 않습니다.

실무 기술과 교육 경험, 완료한 구현과 향후 개선 방향을 구분합니다. 심리검사, 결제, 소셜 로그인, CLIP report와 게시판 사례는 확인한 코드와 담당 경험을 바탕으로 설명합니다. 업무 소스와 인증 정보는 포함하지 않습니다.

응답 유지 데모는 예시 4문항을 두 화면으로 나눠 브라우저 메모리에 선택값을 유지합니다. 선택·페이지 이동 때 저장과 복원 피드백을 표시합니다. 실제 검사 화면이 아니며, 새로고침하면 초기화됩니다. 응답 전송이나 채점은 하지 않습니다. 실제 업무 구현의 localStorage 활용은 본문에 별도로 적었습니다. 리포트는 실제 출력물 대신 연동 구조를 표현한 HTML 도식입니다.

## 구성

- `index.html`: 이름, 목차, 본문, 탐색 메뉴
- `slides.js`: 콘텐츠, 사례별 렌더링, 전환, 응답 유지 데모
- `styles.css`: 서체, 디자인 토큰, 사례 구성, 반응형과 상호작용
- `fonts/`: Pretendard 로컬 폰트
