# 송다원 Java Backend Portfolio

Java 백엔드 개발 경험을 소개하는 HTML/CSS/JavaScript 포트폴리오입니다. `index.html`을 열면 동작하며 빌드나 서버가 필요하지 않습니다.

## 디자인과 정보 구조

- 장식용 챕터 배지, 그라데이션 제목, 슬라이드 카드 프레임을 제거했습니다.
- 이름이 보이는 데스크톱 목차와 모바일 고정 이동 메뉴로 사례를 탐색합니다.
- 경력은 업무 범위, 기술은 사용 맥락, 결제는 처리 순서, 로그인은 회원 분기 구조로 설명합니다.
- Pretendard를 유지하고 블루는 탐색·선택, 틸은 데이터·결과, 앰버는 예외 설명에 사용합니다.
- 입력 영역과 참고 설명을 구분하고 표·목록·실제 조작이 필요한 영역에만 경계를 사용합니다.

## 조작

- 목차, 이전·다음 버튼, 좌우 방향키로 이동합니다.
- 모바일에서는 상단 이동 메뉴를 사용하며, 본문은 자연스럽게 스크롤합니다.
- 입력 요소에서 방향키를 사용하면 해당 요소의 기본 동작을 유지합니다.
- 데스크톱에서는 전체 본문이 화면에 들어오는 경우 휠로 전환합니다.
- `#skills`, `#payment`, `#psychology` 등 주소 해시로 사례를 바로 열 수 있습니다.
- 전환 시 짧은 등장 효과를 사용하며, 키보드 조작과 동작 줄이기 설정에서는 생략합니다.

## 콘텐츠와 데모

실무 기술과 교육 경험, 완료한 구현과 향후 개선 방향을 구분합니다. 심리검사, 결제, 소셜 로그인, CLIP report와 게시판 사례는 확인한 코드와 담당 경험을 바탕으로 설명합니다. 업무 소스와 인증 정보는 포함하지 않습니다.

응답 유지 데모는 예시 4문항을 두 화면으로 나눠 브라우저 메모리에 선택값을 유지합니다. 실제 검사 화면이 아니며, 새로고침하면 초기화됩니다. 응답 전송이나 채점은 하지 않습니다. 실제 업무 구현의 localStorage 활용은 본문에 별도로 적었습니다. 리포트는 실제 출력물 대신 연동 구조를 표현한 HTML 도식입니다.

## 구성

- `index.html`: 이름, 목차, 본문, 탐색 메뉴
- `slides.js`: 콘텐츠, 사례별 렌더링, 전환, 응답 유지 데모
- `styles.css`: 서체, 디자인 토큰, 사례 구성, 반응형과 상호작용
- `fonts/`: Pretendard 로컬 폰트
