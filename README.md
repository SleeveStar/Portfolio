# 송다원 Java Backend Portfolio

기존 슬라이드 프레임, Pretendard, 블루·민트 색감과 등장 애니메이션을 유지한 Java 백엔드 포트폴리오입니다. `index.html`을 열어 확인할 수 있습니다. 별도 빌드나 서버가 필요하지 않습니다.

## 내용과 표현

- 실무 기술과 교육 경험을 구분합니다.
- 요청 처리·결제는 단계 흐름, 소셜 로그인은 회원 분기, 데이터 저장은 필드 구조로 설명합니다.
- 심리검사 응답 유지 원리를 방문자가 조작하는 축약 데모로 보여줍니다.
- 검사별 데이터 변환과 외부 API의 채점 역할을 구분합니다.
- CLIP report 출력, 게시판, 완료한 구현과 향후 개선 방향을 정리합니다.

데모는 실제 서비스 화면이나 검사를 복제한 것이 아닙니다. 예시 4문항을 두 화면으로 나눠 브라우저 메모리에 선택값을 유지하며, 새로고침하면 초기화됩니다. 검사 결과를 생성하거나 응답을 전송하지 않습니다. 실제 업무 구현의 localStorage 활용은 설명 본문에 별도로 적었습니다. 리포트 이미지는 연동 구조를 표현한 HTML 도식입니다.

## 조작

- 이전·다음 버튼, 목차 선택, 진행 표시, 좌우 방향키로 이동합니다.
- 입력 요소에서 방향키를 사용하면 해당 요소의 기본 조작을 유지합니다.
- 데스크톱에서는 본문이 화면에 들어오는 경우 휠로 전환합니다.
- 모바일에서는 본문을 스크롤하고 버튼이나 목차로 이동합니다.
- `#payment`, `#psychology`, `#closing` 등 주소 해시로 해당 사례를 바로 열 수 있습니다.
- 동작 줄이기 설정과 키보드 이동 시에는 등장 효과를 생략합니다.

## 구성

- `slides.js`: 콘텐츠, 사례별 렌더링, 전환, 응답 유지 데모
- `styles.css`: 기존 시각 체계, 사례별 구성, 반응형과 상호작용
- `fonts/`: 기존 Pretendard 폰트

내용은 확인한 구현과 담당 경험에 근거합니다. 업무 소스와 인증 정보는 포함하지 않으며, 확인되지 않은 성능 수치나 수행하지 않은 개선을 성과로 적지 않습니다.
