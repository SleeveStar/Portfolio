# 송다원 개발 포트폴리오

Java·Spring MVC 기반 웹 서비스에서 담당한 기능을 소개하는 정적 포트폴리오입니다. 별도 빌드나 외부 라이브러리 설치 없이 `index.html`을 열어 볼 수 있습니다.

## 구성

- 실무 경험과 기술 사용 맥락
- 다문항 심리검사 응답 저장·복원 및 검사별 요청 데이터 변환
- 커리어넷 API와 별도 점수 집계 검사의 처리 방식 구분
- KG이니시스 결제, 카카오·네이버 로그인, CLIP report 4, 공지·문의 게시판
- 현재 구현과 향후 개선 방향을 구분한 회고

실무 설명은 확인한 구현과 작성자의 담당 경험을 기준으로 정리했습니다. 측정하지 않은 성능 수치, 확인되지 않은 대안 비교·테스트 성과는 포함하지 않습니다. 업무 시스템 소스나 인증 정보는 이 저장소에 포함하지 않습니다.

## 보기

- 상단 목차, 이전·다음 버튼, 본문에 포커스한 상태의 좌우 방향키로 이동합니다.
- 각 항목의 URL 해시로 특정 사례를 바로 열 수 있습니다. 예: `#psychology`, `#payment`.
- 휠·터치 스크롤은 본문을 읽는 데 사용합니다.
- `전체 인쇄` 또는 브라우저 인쇄 기능은 모든 항목을 출력합니다.
- 화면이 좁아지면 본문과 비교표가 한 열로 바뀝니다.

## 파일

- `slides.js`: 사례 데이터, 렌더링, 목차·키보드·인쇄 처리
- `styles.css`: 기존 Pretendard 폰트와 다크 배경·블루/민트 색상을 유지한 화면·인쇄 스타일
- `fonts/`: 기존 로컬 폰트 자산

## 콘텐츠 유지 원칙

완료한 구현과 회고의 개선 제안을 구분합니다. 개인 학습과 회사 업무를 섞지 않고, 운영 배포·개선율·테스트 통과는 확인 가능한 근거가 있을 때만 추가합니다.
